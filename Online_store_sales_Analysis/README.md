# 📊 Аанализ продаж на Python

Проект анализа данных интернет-магазина с использованием Python, Pandas и Matplotlib.

## 🎯 Цель проекта

Провести базовый анализ продаж и выявить ключевые закономерности для бизнеса.

## 📈 Что анализируем

- Общие метрики бизнеса (выручка, средний чек, количество заказов)
- Эффективность товарных категорий
- Географическое распределение заказов
- Динамику продаж по месяцам

## 🛠 Технологии

- Python 3.17
- Pandas - анализ данных
- Matplotlib - визуализация
- NumPy - генерация данных
