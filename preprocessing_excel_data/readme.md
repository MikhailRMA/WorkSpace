# Обработчик Excel-выгрузок для анализа тикетов

## Назначение
Система из двух скриптов для автоматической обработки и анализа данных:
1. **excel_splitter.py** - группирует данные по датам и продавцам
2. **filter_tikets.py** - фильтрует данные по типам стран и разбивает по тем же группам дат

## Особенности
- Автоматическая группировка данных по датам и уникальным ID продавцов
- Разделение на части (по 600 уникальных ID в каждом CSV)
- Фильтрация по типам стран (РФ, Глобал, СНГ, пустые значения)
- Сохранение результатов в структурированных папках
- Генерация отчетов в Excel

## Инструкция
### Подготовка данных
1. Для первого скрипта убедитесь в наличии столбцов:
   - `Дата`
   - `ID продавца, на которого подали жалобу` 
   - `SKU`

2. Для второго скрипта требуются столбцы:
   - `ID тикета`
   - `Тип страны` (значения: РФ, Глобал, СНГ или пусто)
   - `Дата`

3. Отсортируйте данные по столбцу "Дата"

### Запуск скриптов
1. Сначала выполните группировку данных:
   ```bash
   python scripts/excel_splitter.py

## Результаты работы
### От excel_splitter.py
1. Папка Внешние_заявители_группировка с:
- Отчетом в report.xlsx
- Подпапками с датами, содержащими:
  - Полные данные (data_*.xlsx)
  - Уникальные SKU (sku_part_*.csv)

### От filter_tikets.py
1. Дополняет папки дат файлами:
- рф_тикеты.csv - только тикеты РФ для этой даты
- глобал_снг_тикеты.csv - тикеты Глобал/СНГ для даты
- пустые_типы.csv - тикеты без указания страны
2. Создает отдельную папку Внешние_заявители_фильтрация с:
- Общими файлами по всем типам стран
- Разбивкой по тем же группам дат
## Настройки
- Изменить лимит (600 ID) → настройте group_size
- Добавить другие столбцы → модифицируйте save_sku_parts()
