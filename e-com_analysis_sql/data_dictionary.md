# 📊 Data Dictionary - E-commerce Analysis

Полное описание структуры данных и таблиц, используемых в проекте анализа интернет-магазина.

## 🗃️ Обзор базы данных

**Название БД:** `e-com`  
**СУБД:** PostgreSQL 17  
**Количество таблиц:** 4  
**Период данных:** Февраль 2023 - Май 2023  

## 📋 Таблица: `customers` (Клиенты)

Хранит информацию о клиентах интернет-магазина.

| Поле | Тип данных | Ограничение | Описание |
|------|------------|-------------|-----------|
| `customer_id` | `SERIAL` | `PRIMARY KEY` | Уникальный идентификатор клиента |
| `name` | `VARCHAR(100)` | `NOT NULL` | Полное имя клиента |
| `country` | `VARCHAR(50)` | `NOT NULL` | Страна проживания клиента |
| `signup_date` | `DATE` | `NOT NULL` | Дата регистрации в системе |

### 🔗 Связи
- `customer_id` → `orders.customer_id` (1 ко многим)

---

## 📋 Таблица: `products` (Товары)

Каталог товаров интернет-магазина.

| Поле | Тип данных | Ограничение | Описание |
|------|------------|-------------|-----------|
| `product_id` | `SERIAL` | `PRIMARY KEY` | Уникальный идентификатор товара |
| `product_name` | `VARCHAR(100)` | `NOT NULL` | Название товара |
| `category` | `VARCHAR(50)` | `NOT NULL` | Категория товара |
| `price` | `DECIMAL(10,2)` | `NOT NULL` | Цена товара в USD |

### 🔗 Связи
- `product_id` → `order_items.product_id` (1 ко многим)

---

## 📋 Таблица: `orders` (Заказы)

Основная информация о заказах.

| Поле | Тип данных | Ограничение | Описание |
|------|------------|-------------|-----------|
| `order_id` | `SERIAL` | `PRIMARY KEY` | Уникальный идентификатор заказа |
| `customer_id` | `INTEGER` | `FOREIGN KEY` | Ссылка на клиента |
| `order_date` | `DATE` | `NOT NULL` | Дата оформления заказа |
| `revenue` | `DECIMAL(10,2)` | `NOT NULL` | Общая сумма заказа |

### 🔗 Связи
- `customer_id` ← `customers.customer_id`
- `order_id` → `order_items.order_id` (1 ко многим)

---

## 📋 Таблица: `order_items` (Позиции заказов)

Детальная информация о составе заказов.

| Поле | Тип данных | Ограничение | Описание |
|------|------------|-------------|-----------|
| `order_item_id` | `SERIAL` | `PRIMARY KEY` | Уникальный идентификатор позиции |
| `order_id` | `INTEGER` | `FOREIGN KEY` | Ссылка на заказ |
| `product_id` | `INTEGER` | `FOREIGN KEY` | Ссылка на товар |
| `quantity` | `INTEGER` | `NOT NULL` | Количество товара в заказе |
| `price` | `DECIMAL(10,2)` | `NOT NULL` | Цена товара на момент заказа |

### 🔗 Связи
- `order_id` ← `orders.order_id`
- `product_id` ← `products.product_id`

---

## 🔗 Схема связей между таблицами

customers (1) → (N) orders (1) → (N) order_items (N) → (1) products
Описание связей:

Один клиент может совершить множество заказов

Один заказ может содержать множество позиций

Один товар может присутствовать в множестве позиций заказов
