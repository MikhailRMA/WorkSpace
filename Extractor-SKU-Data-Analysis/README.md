# Анализ пользовательского поведения: Веб-приложение Extractor SKU

## 📌 О проекте
Проект по анализу данных из Яндекс.Метрики для веб-приложения **Extractor SKU** - инструмента автоматизации извлечения артикулов из текстов и ссылок.

**Цель анализа:** Оценить эффективность приложения, понять поведение пользователей и выявить точки роста для улучшения продукта.

## 📊 Ключевые метрики
- **111 визитов** за анализируемый период
- **27 уникальных пользователей**
- **Среднее время на сайте:** 89 секунд (1.5 минуты)
- **Глубина просмотра:** 1.3 страницы/визит
- **Процент отказов:** 0.8%
- **Основные устройства:** ПК (98.2% визитов)

## 📈 Основные выводы

### Положительные результаты:
✅ **Высокая эффективность инструмента** - низкое время использования (89 сек) при минимальных отказах (0.8%) свидетельствует об интуитивно понятном интерфейсе

✅ **Стабильная аудитория** - 27 уникальных пользователей демонстрируют востребованность решения

✅ **Качественные визиты** - средняя глубина просмотра 1.3 стр/визит показывает целенаправленное использование

### Области для улучшения:
🔸 **Мобильная аудитория** - всего 2 визита со смартфонов, что указывает на необходимость мобильной адаптации

🔸 **Повторное использование** - анализ возвращаемости пользователей требует дополнительного изучения
