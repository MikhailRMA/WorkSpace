# 📊 Автоматизация обработки трафика претензий на продавцов (Excel → DataLens)

Полный цикл: ETL, бизнес-логика (маппинг брендов, контроль документов, исключения), прогнозирование и дашборд в Яндекс DataLens.

## 🧩 Бизнес‑задача

Интернет-платформа (маркетплейс) получает ежедневно Excel‑выгрузки с жалобами на продавцов.  
Сотрудники должны:
- отсеять обращения с пустым SKU, нулевым ID продавца, обращения из стран СНГ/Глобал;
- проверить, соответствует ли заявленный бренд разрешённому для данного отправителя (маппинг почтовых ключей);
- проверить статус документов на бренд и срок их действия;
- выгрузить отдельно одобренные жалобы (можно закрывать тикеты), исключённых продавцов, а также требующие ручной проверки.

**Результат:** автоматический конвейер, который экономит часы ручного труда, исключает ошибки и даёт руководителю дашборд с метриками и прогнозом.

## 🚀 Функциональные возможности

### 1. Автоматическая обработка выгрузок
- Объединение нескольких Excel‑файлов в один датафрейм.
- Удаление лишних столбцов (`Текст обращения`, `Книги…`, `Издательство`, `Текст обрезан`).
- Фильтрация по бизнес‑правилам:
  - строки с **пустым SKU** → отдельный Excel + CSV с ID тикетов;
  - строки с **ID продавца = 0** → отдельный Excel + CSV `тикеты_1р.csv`;
  - строки с типом страны **«Глобал» или «СНГ»** → отдельный Excel + CSV `тикеты_КБ.csv`;
  - строки с типом страны **«РФ»** → проходят дальнейшую проверку.

### 2. Проверка брендов и документов (основная бизнес‑логика)
- Из почты отправителя извлекается **ключ** (часть до `@`, затем до первого дефиса).
- По ключу из справочника `brand_mapping.xlsx` определяется список **разрешённых брендов**.
- Если фактический бренд входит в разрешённый список, проверяются:
  - статус документа = `одобрен` или `approved`;
  - срок действия документов не истёк.
- **Результат:**  
  - `Выгрузка_есть_документы.xlsx` + CSV (тикеты продавцов с одобренными документами)  
  - `Выгрузка_РФ_на_проверку.xlsx` – строки для ручной проверки

### 3. Исключения (чёрные списки)
- **По ID продавца** (файл `excluded_sellers.xlsx`) – строки сохраняются в `Выгрузка_РФ_исключения.xlsx` + CSV тикетов.
- **По email / ключу почты** (файл `exclusion_of_processing.xlsx`) – строки полностью удаляются из обработки и сохраняются отдельно.

### 4. Аналитика по брендам (накапливаемая витрина)
- Формируется файл `brand_analytics.xlsx` с двумя листами:
  - `brand_daily` – ежедневная статистика по ключу (тикетов, одобрено, ручная проверка, несовпадение бренда, нет маппинга);
  - `brand_stats` – итоги за всё время (суммы, доля ручной проверки, список разрешённых брендов).

### 5. Прогноз на квартал
- На основе накопленного файла `метрики.xlsx` строится **пропорционально-линейный прогноз**:
  - прогнозируется базовый показатель `Тикетов всего`;
  - доли остальных метрик берутся за последние 3 месяца;
  - результат сохраняется в `analytics/прогноз_год_Qквартал.xlsx` и CSV.
- Правило выбора квартала: если до конца текущего квартала >15 дней – прогноз на текущий, иначе на следующий.

### 6. Метрики для дашборда
- Для каждого исходного файла записываются:  
  `Дата` (из имени файла), `Источник`, `Тикетов всего`, `Тикеты пустые`, `Тикеты 1р`, `Тикеты КБ`, `Тикеты РФ`, `Тикеты продавцов исключения`, `Тикеты продавцов с одобренными документами`, `Всего строк`, `РФ всего строк`, `На ручную проверку`, `Среднее время обработки (дни)`, `Дата обработки`.
- Все строки дописываются в `analytics/метрики.xlsx`.

### 7. Дашборд в Яндекс DataLens 
Основная структцра:
- Текущая ситуация
- Процесс проверки
- Аналитика и тренды
- Срез по брендам

## 🧪 Запуск (для не‑технического сотрудника)

1. Скачать папку с `script.exe` и вспомогательными файлами.
2. Поместить Excel-выгрузки в папку `input`.
3. Запустить `script.exe` двойным щелчком.
4. Дождаться сообщения «Обработка завершена!» → нажать Enter.
5. Результаты – в папке `results`.

> **Внимание:** программа не требует установки Python, все зависимости уже внутри .exe.

## 📊 Пример бизнес‑эффекта (для резюме)

- **Сокращение ручного труда:** обработка 10 файлов (3000+ строк) – с 3–4 часов до 2–3 минут.
- **Исключение ошибок:** 100% единообразие фильтрации.
- **Прозрачность:** каждый шаг залогирован, есть витрина метрик и прогноз.
- **Масштабируемость:** добавление новых брендов – через правку Excel, без изменения кода.

## 🧰 Как собрать .exe самостоятельно (для разработчика)

```bash
pyinstaller --onefile --console \
    --hidden-import=pandas \
    --hidden-import=openpyxl \
    --hidden-import=pandas._libs.tslibs \
    --hidden-import=openpyxl.cell._writer \
    script.py

```
