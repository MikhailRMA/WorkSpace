# 🔍 Extractor SKU: Парсинг коротких ссылок Ozon

*Исследовательский проект по автоматизации извлечения артикулов из коротких ссылок маркетплейса Ozon*

---

## 🎯 Задача

Реализовать функционал извлечения артикулов товаров из коротких ссылок Ozon для интеграции с основным веб-приложением SKU Extractor Tool. Стандартные HTTP-запросы блокируются антибот-системой Ozon.

## 💡 Решение

Разработан специализированный модуль парсинга с использованием:
- **Selenium WebDriver** для полной эмуляции поведения реального пользователя
- **ChromeDriver** с настройками для обхода базовых детектов ботов  
- **Railway** для хостинга с поддержкой браузерной автоматизации
- Python-скрипты для обработки редиректов и извлечения артикулов

## 🚀 Ключевые особенности

- Обход первичной защиты Ozon через эмуляцию реального браузера
- Автоматическое определение конечного URL из коротких ссылок
- Интеграция с основным приложением SKU Extractor
- Развертывание на Railway с решением проблем совместимости Selenium

## 📊 Результаты исследования

### ✅ Достижения:
- Успешная настройка Selenium в облачной среде Railway
- Преодоление ограничений хостингов для браузерной автоматизации  
- Эмуляция пользовательского поведения для обхода базовой защиты

### ⚠️ Выявленные ограничения:
- Ozon использует продвинутые системы детекта (анализ отпечатков браузера, поведенческие паттерны)
- Даже автоматизированные браузеры идентифицируются и блокируются
- Надежное решение требует коммерческих антидетект-инструментов
