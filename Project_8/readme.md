# Задачи:

Изучение данных о транзакциях — поиск несоответствий, отсутствующих данные, выбросы, правильно идентифицированные элементы категорий, числовые данные во всех таблицах. В случае выявления аномалий, внести необходимые изменения в набор данных и сохраните его.

Изучить данные о клиентах — проверить, нет ли в них похожих проблем, поиск пустых полей. Объединить данные о транзакциях и клиентах, чтобы они были готовы к анализу.

Анализ данных и сегменты клиентов — в ходе анализа убедиться, что определены показатели — общий объём продаж, факторы, влияющие на продажи, откуда поступают самые высокие объёмы продаж и т.д. Изучить данные, создать диаграммы и графики, а также отметить любые интересные тенденции и/или идеи.

Глубоко погрузиться в сегменты клиентов — сформулировать рекомендации на основе полученной информации, определить, на какие сегменты следует ориентироваться, если размеры пакетов относительны, и сформулировать общий вывод на основе анализа.
