# 📊 Анализ поведения пользователей мобильного приложения

Пет-проект анализа пользовательского поведения, расчет ключевых метрик и выявление точек роста.

## 🎯 Цель проекта

- Провести разведывательный анализ данных (EDA)
- Рассчитать ключевые продуктовые метрики (DAU, WAU, MAU, конверсия, удержание)
- Построить воронку событий пользователя
- Провести когортный анализ удержания
- Проанализировать метрики по сегментам (страны, устройства)
- Сформулировать выводы и рекомендации для продукта

## 📈 Что анализируем

- Общие метрики бизнеса (выручка, средний чек, количество заказов)
- Эффективность товарных категорий
- Географическое распределение заказов
- Динамику продаж по месяцам

## 🛠 Технологии

- Python 3.13
- Pandas - анализ данных
- Matplotlib - визуализация
- Seaborn - визуализация
- NumPy - генерация данных
