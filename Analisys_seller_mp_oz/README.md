# Анализ эффективности продаж и ассортимента интернет-магазина

## О проекте
Данный проект был выполнен в рамках анализа данных для интернет-магазина, продающего аксессуары для телефонов на маркетплейсах. Цель проекта — повышение прибыльности бизнеса за счет оптимизации ассортимента, ценовой политики и выявления ключевых метрик.

**Примечание**: Проект выполнен для реального заказчика. Данные анонимизированы в соответствии с NDA. Бизнес-инсайты и методология представлены в оригинальном виде.

## Цели
- Провести анализ продаж и ассортимента.
- Выявить товары-лидеры и аутсайдеры.
- Проанализировать сезонность и тренды продаж.
- Дать рекомендации по оптимизации бизнес-процессов.

## Данные
В проекте использовались два анонимизированных набора данных:
- `anonymous_seller_product`: информация о товарах
- `anonymous_oz_sales_data`: информация о продажах

## Методы и технологии
- **Языки программирования:** Python
- **Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn, Plotly
- **Инструменты:** Jupyter Notebook, DataLens
- **Методы:** ABC-XYZ анализ, анализ временных рядов, анализ клиентов (RFM), анализ ассоциаций
