# 📊 Аналитический дашборд: Динамика претензий

Проект представляет собой интерактивный дашборд для анализа и визуализации динамики поступления претензий. Разработан в **Yandex DataLens** с использованием реальных (обезличенных) бизнес-данных.

![Dashboard Preview](https://github.com/MikhailRMA/WorkSpace/blob/main/dynamics_of_claims/Screen.png)

## 🎯 Цель проекта

Создать удобный инструмент для мониторинга и анализа потока претензий, который позволяет:
- Отслеживать динамику в реальном времени
- Выявлять проблемные периоды и тенденции
- Принимать обоснованные решения на основе данных
- Автоматизировать ежемесячную отчетность

## 📈 Ключевые метрики и визуализации

### 1. **Индикаторы (KPI)**
- **Общее количество претензий** за выбранный период
- **Количество по месяцам** (отдельные индикаторы)
- **Динамика текущего месяца** к предыдущему (% изменение)

### 2. **Графики и диаграммы**
- 📈 **Линейный график динамики** с двумя метриками:
  - Ежедневное количество претензий
  - Скользящее среднее за 7 дней (сглаженный тренд)
- 📊 **Накопительный итог** (кумулятивная кривая)
- 🏗️ **Столбчатая диаграмма по месяцам** с градиентной раскраской
- 📅 **Распределение по дням недели** в процентах от общего количества

### 3. **Интерактивные элементы**
- 🔍 **Фильтр по периоду** (произвольный диапазон дат)
- 🔗 **Связанные элементы** (взаимодействие между чартами)
- 📱 **Адаптивный дизайн** для разных устройств

## 🛠️ Техническая реализация

### Стек технологий
- **Yandex DataLens** — платформа для визуализации и анализа данных
- **SQL** — для создания вычисляемых полей и агрегаций
- **Датасет** — таблица с обезличенными данными о претензиях

### Ключевые SQL-запросы

```sql
-- Скользящее среднее за 7 дней
AVG(COUNT([Дата])) OVER(PREVIOUS 7 [Дата] ROWS)
``` 
```sql
-- Накопительный итог
SUM(COUNT([Дата])) OVER(ORDER BY [Дата])
``` 
```sql
-- Процент от общего количества
COUNT([Дата]) * 100.0 / SUM(COUNT([Дата]) TOTAL)
``` 
```sql
-- Динамика месяца к месяцу
(COUNT_IF([Дата], MONTH([Дата]) = MONTH(TODAY())) - 
 COUNT_IF([Дата], MONTH([Дата]) = MONTH(DATETIME_SUB(TODAY(), INTERVAL 1 MONTH)))) * 100.0 /
NULLIF(COUNT_IF([Дата], MONTH([Дата]) = MONTH(DATETIME_SUB(TODAY(), INTERVAL 1 MONTH))), 0) 
```

### 🚀 Как использовать

#### Для просмотра

1. Откройте дашборд в Yandex DataLens

2. Выберите интересующий период в фильтре

3. Взаимодействуйте с элементами:

4. Наведите курсор на график для деталей

5. Кликните на месяц в диаграмме для фильтрации

6. Используйте инструменты масштабирования

####  Для анализа

**Выявление трендов:** Смотрите линейный график со скользящим средним

**Поиск аномалий:** Анализируйте пики на столбчатых диаграммах

**Распределение нагрузки:** Изучайте тепловую карту по дням недели

**Прогнозирование: Используйте** накопительный итог для оценки объемов

### 💡 Бизнес-инсайты

Дашборд позволяет ответить на ключевые вопросы бизнеса:

| Вопросы | Ответы через дашборд |
| --- | --- |
| Растет ли количество претензий? | Линейный график + тренд |
| В какие дни пиковая нагрузка? | Диаграмма по дням недели |
| Какой месяц был самым проблемным? | Столбчатая диаграмма с градиентом |
| Когда ситуация начала ухудшаться? | Накопительный итог + точки перегиба |
| Насколько стабильна ситуация? | Скользящее среднее (волатильность) |
