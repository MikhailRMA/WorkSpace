# 🛍️ Brand Detector App

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Pandas](https://img.shields.io/badge/Pandas-2C2D72?style=for-the-badge&logo=pandas&logoColor=white)

Веб-приложение для автоматического определения и заполнения брендов в табличных данных на основе анализа текстовых полей.

## 🚀 Возможности

- **Автоматическое определение брендов** - интеллектуальный поиск по названию и описанию товаров
- **Управление словарем брендов** - добавление, редактирование, удаление брендов и ключевых слов
- **Детальная аналитика** - визуализация эффективности работы алгоритма
- **Логирование процессов** - полный трекинг всех операций определения брендов
- **Поддержка форматов** - работа с Excel (.xlsx, .xls) и CSV файлами
- **Экспорт результатов** - скачивание обработанных данных в нужном формате

## 🛠 Технологии

- **Frontend**: Streamlit
- **Data Processing**: Pandas
- **Text Analysis**: Regular Expressions
- **File Handling**: OpenPyXL


## 📊 Формат данных

Приложение работает с таблицами, содержащими следующие обязательные колонки:

- Колонка	- Тип	Описание
- название	- string	Наименование товара
- описание	- string	Описание товара
- бренд -	string	Бренд (может быть пустым)

#### Пример данных:

**csv**

название,описание,бренд

Кроссовки Nike Air Max,Спортивные кроссовки для бега,

Смартфон Samsung Galaxy,Новый флагман с камерой 108 Мп,

Ноутбук Apple MacBook Pro,13 дюймов, процессор M2,


## 🎯 Как использовать

1. Загрузка данных
Перейдите на вкладку "Главная"

Загрузите Excel или CSV файл

Просмотрите предварительные данные и статистику

2. Настройка словаря брендов
Перейдите в "Управление словарем"

Добавьте нужные бренды и ключевые слова

Используйте синонимы и различные написания

3. Обработка данных
Нажмите "Заполнить бренды автоматически"

Дождитесь завершения обработки

Просмотрите результаты и метрики

4. Анализ и экспорт
Изучите аналитику во вкладке "Аналитика и логи"

Скачайте обработанные данные в нужном формате

#### 🔧 Настройка словаря брендов

Словарь брендов настраивается в формате:

json

{

  "Nike": ["nike", "найк", "nike air", "air max"],
  
  "Samsung": ["samsung", "самсунг", "galaxy", "note"],
  
  "Apple": ["apple", "эпл", "iphone", "macbook"]
  
}

#### Советы по настройке:

Добавляйте различные написания (транслит, опечатки)

Включайте популярные модели товаров

Используйте специфичные для бренда термины

## 📈 Метрики и аналитика

Приложение предоставляет детальную аналитику:

- Покрытие данных - процент заполненных брендов до и после обработки

- Эффективность ключевых слов - какие слова чаще всего срабатывают

- Распределение брендов - статистика по найденным брендам

= Детальные логи - полная история всех операций

## 🐛 Решение проблем

Частые вопросы

Q: Файл не загружается

A: Проверьте формат файла и наличие обязательных колонок

Q: Бренды не определяются

A: Проверьте словарь брендов и добавьте нужные ключевые слова

Q: Ошибка кодировки

A: Используйте UTF-8 кодировку для CSV файлов

#### Логирование ошибок

Все ошибки логируются в интерфейсе приложения. Для дополнительной диагностики проверьте:

- Соответствие формата данных

- Наличие необходимых прав доступа к файлам

- Корректность словаря брендов
