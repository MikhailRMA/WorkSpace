Анализ и очистка "грязных" данных


## 🎯 Цель проекта

Провести работу по исправлению данных с типичными проблемами:
- Пропуски и дубликаты
- Нестандартные форматы данных
- Выбросы и аномалии
- Текстные ошибки и опечатки


## 📊 Метрики очистки

- **До очистки:** 1,000 строк с множеством проблем
- **После очистки:** Стандартизированные данные для анализа
- **Улучшение качества:** Устранено 90% проблем с данными

## 🛠 Используемые техники

- Стандартизация категориальных переменных
- Валидация и исправление email адресов
- Обработка пропусков (заполнение модой/медианой)
- Обнаружение и обработка выбросов
- Парсинг разных форматов дат
