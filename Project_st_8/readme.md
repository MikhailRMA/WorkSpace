## Описание эксперимента
Перед вами таблица, где числовая переменная – непрерывная. Задача – сравнить группы двумя способами: бутстрапом и u-тестом


### Задачи
1. Сравните результат между тестом и контролем по двум кейсам:

  + Примените бутстрап (с np.mean) и критерий mann-whitney, а потом сравните p-value
  + Примените бутстрап (с np.median) и критерий mann-whitney, а потом сравните p-value.
  
2. Напишите выводы, которые можно сделать на основе анализа примененных критериев
3. Создание функции, которая поможет проверять гипотезы с помощью bootstrap
4. Сравнивание средние значения в тестовой и контрольной группах с помощью бутстрапа
5. Сравнивание тестовой и контрольной группы с помощью U-критерия Манна-Уитни

### Описание данных
- value – значения метрики
- experimentVariant – Вариант теста (Control – контроль, Treatment – тест)
