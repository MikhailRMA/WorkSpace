# 📊 Анализ A/B теста: Влияние новой рекомендательной системы на продажи

Анализ A/B теста для оценки эффективности новой рекомендательной системы в интернет-магазине. Проект проверяет гипотезу о влиянии системы на средний чек покупателей.

## 🎯 Бизнес-задача

Определить, стоит ли внедрять новую систему рекомендаций для всех пользователей на основе статистического анализа ее эффективности.

## 📈 Данные

Искусственно сгенерированный датасет, имитирующий реальные данные A/B теста:
- **Группа A**: контрольная группа (старая система)
- **Группа B**: экспериментальная группа (новая система)
- **Размер выборки**: по 1000 пользователей в каждой группе

## 🔎 Методы анализа 
- Описательная статистика (средние, медианы, стандартные отклонения)
- Визуализация распределений (гистограммы, boxplot'ы)
- Статистическая проверка гипотез (t-тест для независимых выборок)
- Расчет доверительных интервалов

## 🛠 Технологии

- Python 3.13
- Pandas - анализ данных
- NumPy - генерация данных
- Matplotlib, Seaborn - визуализация
- SciPy - статистические тесты
